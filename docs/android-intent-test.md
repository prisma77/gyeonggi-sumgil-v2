이는 실제 Android 앱의 Gemini 요청·파싱·결과 표시 검증이다.
AI 대기질/날씨 상담의 새로운 유료 요청이나 카카오 도보 API 호출은 수행하지 않았다.
에뮬레이터 위치에서 관측 자료가 없었으므로 현재 대기질/날씨 자료의 정확도를 승인하지 않는다.
에뮬레이터 x86_64 환경은 카카오 지도 SDK 미지원 안내 대상이므로 실제 지도 검증과 구분한다.

## 작은 구현 범위

- `AiIntentReviewPanel`: 디버그 빌드의 AI 상담 탭에만 표시하는 수동 시험 패널.
- 자유 입력 대신 공개 장소 예시 8건을 선택한다. 현재 좌표·주거 주소·관측 자료는 전송하지 않는다.
- `AiIntentProbeCases`와 `intentProbeFailures`: PC/JVM 실험과 앱에서 같은 시험 조건/판정 사용.
- 장소 교체, 임의 거리, 원하지 않은 순환·왕복, 접근 거리 제외 누락 등을 검사한다.
- 결과에 `해석 조건 통과 · 경로 추천 미승인`을 표시한다. 실제 경로 생성에 연결하지 않는다.
- 한 번 클릭할 때 한 번만 요청, 응답 전 버튼 비활성화, 자동 재시도 없음.
- 화면 내 호출 8회 제한. 화면을 떠났다가 다시 열거나 앱을 재시작하면 초기화된다.
  이 값은 결제 계정의 전체 지출 제한이 아니다.
- API 오류 원문이나 인증 키를 UI/로그에 출력하지 않는다.
- 출시 빌드에서는 시험 패널을 표시하거나 이 패널의 API 요청을 수행하지 않는다.

## 사용 방법

1. Android Studio에서 저장소 루트를 열고 debug 앱을 실행한다.
2. `AI 상담` → `산책 요청 해석 시험` → 시험 예시 선택.
3. `선택한 예시로 AI 조회 1회 (유료)` 버튼을 누른다.
4. 반환 장소·거리·형태·확인 질문과 검사 결과를 확인한다.
5. 실제 코스는 경로 탭의 별도 검증 흐름으로 시험한다. 해석 통과를 코스 승인으로 취급하지 않는다.

원본 입력은 공개 OSM 보행 노드이며, 주거 주소나 집↔공원 접근 경로 조회는 이번 시험에 없다.

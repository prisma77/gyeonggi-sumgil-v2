# 검사 표시·원본 보행망·복수 순환 탐색 — 2026-10-10

이후 미사 3km 누락의 원인 확인과 arc 조합·경유점 선택·명시적인 2회 조회 개선은 [후속 거리 탐색 기록](misa-distance-search-fix.md)을 참조한다. 아래 시험은 직전 탐색 방식의 이력이다.

[미사 원인 검토](misa-route-cause-review.md)의 후속 구현이다. 날씨·대기질·AI 흐름은 바꾸지 않았으며, 실제 경로 호출은 사용자가 선택한 후보에만 실행한다.

## 검사 결과 표시 분리

- 선형 조건의 통과·실패·판정 보류를 개별 검사 결과에 따라 표시한다. 서버의 실험 상태 `NOT_ACCEPTED`를 모든 경로의 검사 실패로 표현하지 않는다.
- 실제 API 선은 통과 파랑, 보류 노랑, 실패 빨강이다. OSM 원본 미리보기 주황과 구분한다.
- 현재 출입·통행은 별도 미확인 상태다. 선형 통과도 현장 통행이나 추천 품질 승인이 아니다.
- API step을 그대로 별도 선으로 그린다. 끊어진 좌표를 이어 붙이지 않는다.

## 보행망·교량 검사

- 선택한 한 코스와의 일치율과 전체 확보 원본 보행망과의 일치율을 분리한다. 후보 생성의 수역 주변 edge 제한을 전체 보행망 정의로 사용하지 않는다.
- 원본 foot 방향·접근 금지·barrier·tunnel·conditional access를 반영한다. API 선형을 20m 이내 원본 edge와 방향으로 대조하며 90% 이상은 원본 선형 조건 통과다. 현재 출입 가능성과 API 높이/layer는 확인하지 못한다.
- 50m 공간 격자로 가까운 edge만 검사한다. 색인·대조 작업 총 200만 회 한도를 넘으면 부분 일치율을 정상 결과로 표시하지 않는다.
- API step 사이가 끊겨도 두 끝점이 동일 원본 edge 주변에 있는지 근거만 표시한다. 2m 이내·유일한 근접 대응을 요구하며, 경로 좌표나 기존 1mm 연결 판정 기준을 바꾸지 않는다.
- 수역을 통과한 API 표본은 양끝이 수역 밖에 있고 원본 노드로 연결된 보행 허용 교량과 5m 이내·방향을 대조한다. 양의 layer·완전한 원본 geometry·접근 조건을 요구한다.
- 교량 대응은 원본 선형 근거다. 현재 통행·API layer는 미확인으로 남으며, 교량 대응으로 전체 수역 순환·반복·교차 검사를 건너뛰지 않는다.

## 목표 거리별 복수 순환 탐색

- 확보 원본 graph에서 전체 수역을 둘러싸는 단순 cycle을 구한다. 원본 edge 제외 조합을 바꿔 대안을 찾으며 가상 연결선이나 반복으로 길이를 채우지 않는다.
- 기본 한도는 24회 시도·10초·최대 3개 후보다. 반대 방향·시작점만 다른 같은 edge cycle은 중복 제거한다.
- 목표 거리 입력 시 원본 cycle과 API 반환 거리를 각각 ±10%로 검사한다. 거리를 비우면 한 바퀴 조건이며 임의 기본 거리를 넣지 않는다. 집↔공원 접근 거리는 포함하지 않는다.
- 한도 안에서 탐색한 대안만 비교한다. 전수 탐색·최적 코스 보장은 없다. 결과가 없으면 탐색 한도 도달과 후보 없음 상태를 구분하고, 실제 경로 API는 호출하지 않는다.
- 후보 계산·선택은 추가 외부 API를 호출하지 않는다. 최대 5개 실제 경유점을 유지하고 API 반환 선형을 별도 검사한다.

## 검증 결과

- Python 경로 검사 140개 + 장소·선택 원본·검증 서버 41개, 총 181개 통과.
- Kotlin 단위 테스트 55개 통과, 수동 유료 Gemini 실험 2개 건너뜀. APK 빌드·Android lint 성공(오류 0, 경고 11).
- 복수 원본 cycle, 거리 불일치를 반복으로 채우지 않음, 원본 보존, 금지 방향·접근 조건, 교량 연결/layer, 대체 원본 보행로, 분석 한도 및 멀리 떨어진 다수 edge의 공간 색인을 검사했다.

### 원천호수 3km — 실제 API 대조

기존에 독립 확보한 원본을 사용했다. 원본 후보는 3,017.1 / 3,123.7 / 3,156.9m였고 첫 후보만 SHORTEST로 실제 API 1회 조회했다. 미조회 후보의 API 품질 순위는 비교하지 않았다.

- HTTP 200 / OK, API 3,204m·3,167초·step 13개. 목표 2,700~3,300m 범위 통과.
- 원본 보행망 일치율 100%, 선택 코스 일치율 약 63.8%. 원본의 다른 보행로 사용을 전체 보행망 이탈로 처리하지 않았다.
- 수역 통과 표본 3개는 원본 연결 교량에 대응했으며 미대응 표본 0개. 현재 통행·API layer는 미확인이다.
- 약 0.000885m step 차이는 기존 수치 동등 기준 안이다. 그러나 선형 교차 7건과 반복 22.1m 검토가 남아 최종 선형은 **판정 보류**다. 3km 거리 통과를 호수 한 바퀴 통과로 설명하지 않는다.

### 미사호수 — 탐색 범위 확인

새로 확보한 원본에서 한 바퀴 후보 1,887.5 / 1,901.2 / 1,934.7m를 얻었다. 3,000m 요청은 24회 시도·서로 다른 cycle 16개를 검사했으며, 검사한 길이 범위 1,830.0~2,118.9m에서 후보를 얻지 못했다. 이 결과는 제한된 원본·탐색 안의 결과이며 미사에 3km 코스가 없다는 의미가 아니다. 3km 후보 계산에서 도보 API 호출은 없었다.

공간 색인 개선 전 첫 후보의 실제 BROAD_FIRST 응답(1,781m·1,681초)은 전체 보행망 분석 한도를 드러냈다. 이 중간 결과를 개선 후 검사 통과의 증거로 사용하지 않는다.

실기기 연결 결과는 아래에 별도 기록한다. 신규 원본·실제 API 경로·기기 화면은 RAM에서 검사했으며 원본 응답이나 지도 이미지를 새 파일로 저장하지 않았다. Gemini 호출은 없다.

### Xiaomi 실기기 — 최종 APK 연결

- 첫 원본 확보 요청은 실패 안내 후 멈췄다. 자동 재시도·대체 원본·도보 조회가 없었다. 구체적인 외부 실패 원인은 확보하지 못했다.
- 별도 수동 시험은 검색 후 10분 유효기간을 넘겨 원본 요청 전에 중단됐다(해당 세션 OSM 0회·도보 0회). 이를 OSM의 두 번째 실패로 세지 않는다.
- 새 검색에서 미사호수공원을 직접 선택하고 원본을 확보했다. POI에서 약 132m 떨어진 이름 없는 수역은 지도의 미사호수공원 본 수역과 남쪽 연결 선형을 확인한 후 선택했다. 가까운 수역을 자동으로 같은 장소라고 승인하지 않았다.
- 3,000m 입력은 24회 시도·16개 순환 대조 후 탐색 한도 안내, 도보 0회를 확인했다. 거리를 비워 한 바퀴 후보를 다시 계산하면 1,888 / 1,901 / 1,935m 3개를 표시했다.
- 두 번째 1,901m 원본 후보만 BROAD_FIRST로 조회했다. HTTP 200 / OK, API **1,784m·1,686초·step 25개**, 경유점 차이 0.2·0.6·0.5·1.1·0.3m, 방문 순서 통과.
- 전체 원본 보행망 대조 **99.1%**, 선택한 원본 순환선 일치율 68.8%. 다른 원본 보행 구간 사용을 표시하고 보행망 이탈 실패와 구분했다.
- 수역 내부 표본 1개가 접근 태그·노드 연결·양의 layer를 대조한 원본 교량과 대응, 미대응 표본 0개. API layer·현재 통행은 미확인이다.
- 13→14 step 차이 **0.410m**의 양끝은 같은 원본 edge 부근이나 API 선형은 그대로 불연속이다. 반복 **27.1m** 검토도 남아 최종 결과는 **선형 조건 판정 보류**, 실패 없음이다. 현재 출입·통행 미확인 문구와 노란 API 선을 실제 화면에서 확인했다.
- 지도 내부 단일 터치 드래그 전후 지도 중심이 이동하고 외부 UI 위치는 유지됐다. 현재 앱 PID의 crash buffer에 FATAL EXCEPTION 없음. 같은 최종 APK의 x86 에뮬레이터도 현재 PID의 crash record가 없지만, SDK 지원 제한 때문에 실제 지도 품질 시험으로 세지 않는다.
- 이 후속 작업 전체 실제 호출 합계: 카카오 장소 10회·OSM 3회(실패한 요청 포함)·도보 3회·Gemini 0회. 최종 성공 실기기 세션은 장소 3회·OSM 1회·도보 1회다. 중간 원본 분석 한도 진단과 만료 세션을 포함한 합계이며 이전 문서의 시험과 합산하지 않는다.

## 남은 완료 기준

검사 근거 분리·복수 후보 생성 연결은 완료했으나 추천 코스 품질 전체 완료는 아니다. API step의 실제 연속성, 반복/교차 해소, 실제 출입·통행, 미사 3km에 필요한 원본 범위·대상 정의, 여러 **실제 API** 후보의 비교가 남는다. 엄격한 연결 기준을 완화하거나 임의 선분을 추가해 이번 결과를 통과로 바꾸지 않았다.

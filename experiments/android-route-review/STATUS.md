# 단계 실행 상태 — 2026-10-08

> 후속 사용자 요청으로 기존 앱/홈 UI를 유지하는 방향으로 변경했다.
> 현재 앱 패키지는 `com.gyeonggisumgil.app`이며 이 문서의 `.review` 실행/401은 이전 실험 관측이다.
> 현재 통합 상태는 `docs/reboot-route-integration.md` 참조. PC bridge는 계속 사용한다.

## 구현·실행 확인

- 별도 패키지 `com.gyeonggisumgil.review`, 별도 Gradle 프로젝트 생성.
  기존 tracked 파일 diff 없음. 기존 설치 앱을 덮어쓰지 않음.
- 공식 Android SDK 안내의 2.15.2 사용. compile/target SDK 34, min 28,
  Kotlin 1.9.10, AGP 8.4.0, Gradle 8.6. 로컬 실행 JBR 21.0.5.
  보유 빌드 환경의 실험용 설정이며 최종 서비스 스택 확정으로 해석하지 않음.
- 시험 입력 직접 선택, 경유점 5개/동일 출발·도착, 3개 route_mode,
  실제 API step 선형과 요청점 번호·거리·시간·검사 실패·미해결 항목 표시 코드 구현.
- REST 키는 PC loopback 서버에서만 사용. APK 전체 entry를 읽어 현재 REST 키 값이
  포함되지 않았음을 확인. 키 값은 출력하지 않음. native 키는 SDK용 앱 설정.
- `assembleDebug` 성공. 최종 APK 40,893,119 bytes.
  SDK의 arm64-v8a / armeabi-v7a 네이티브 라이브러리 포함 확인.
- 연결된 실제 기기에 별도 앱 설치·실행 성공. USB reverse 8769 연결.
- 서버 테스트 6개, 기존 경로 검사 테스트 45개 통과. 합성 경계 검사이며 추천 품질 증거 아님.
- 실행 화면에서 시험 입력 목록·mode·조회 버튼·상태·출처 영역의 UI 구조 확인.
  로컬 서버 접속 성공. 입력을 자동 선택하거나 API를 자동 요청하지 않음.
- PC HTTP bridge로 실제 탄천 응답 전달 1회 확인:
  HTTP 200 / API OK, 6 step / 15 coordinates, API 288m / 256초.
  기존 검사기와 전달 구간·좌표 개수 일치. 기하 실패 없음, 반환점·방향 검토 미완료.
  `INCOMPLETE`, `NOT_ACCEPTED` 유지. no-store 응답 확인. 원문·좌표·결과 파일 저장 없음.

## 기기 지도 인증으로 대기 중

- 기기 화면에서 `MapAuthException` 오류 코드 **401** 확인.
  키/앱 정보/설정 중 정확한 원인은 계정 콘솔 확인 전까지 단정하지 않음.
- 지도 인증 실패 시 조회 버튼 비활성화를 UI 트리로 확인.
  Android → bridge → 실제 경로선 지도 표시의 전체 흐름은 **미검증**.
- 사용자가 확인할 설정을 준비:
  패키지 `com.gyeonggisumgil.review`, debug 키 해시 `ExtIkfKlzEW953nke0Y3LuFnwWM=`.
  같은 카카오 앱의 네이티브 키 일치·Android 앱 정보·카카오맵 활성화 확인 요청.
- 설정 완료 후 앱 재시작 → 지도 준비 완료 → 탄천 입력 직접 선택 → 수동 1회 요청 →
  선형과 S/1–5 표시·오류 없음·결과 일치 확인. 다음으로 호수 원본과 비교 입력을 구분해 확인.
- 실제 지도 중첩 시각 확인·현장 통행·호수 전체 순환·불필요 반복/우회 품질 승인은 아직 수행하지 않음.

## 호출·보관

- 이번 단계 도보 REST 1회. 전체 실험 누적 도보 27회, 장소 검색 2회.
  SDK 인증 요청의 실제 차감량은 계정 콘솔 미확인. 서버는 현재 1/6회 사용.
- 서버 세션은 사용자가 설정 후 시험할 수 있도록 실행 상태로 유지.
  앱은 서버에 자동 재접속/자동 route 재조회하지 않음. 호출은 버튼으로만 가능.
- 서버 종료/USB reverse 해제 방법은 README 참조.
- 경로 데이터는 메모리에서만 처리. 앱 종료·새 입력 선택·새 조회/실패 시 이전 결과 폐기.
  이 문서는 기술 관측 수치만 기록하며 경로 원문·좌표 캐시가 아니다.

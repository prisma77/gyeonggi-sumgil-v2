# 다른 장소·구간 비교 실험 — 2026-10-09

## 범위와 입력 출처

원천호수 실험을 특정 공원의 성공·실패로 일반화하지 않기 위해 신대호수와 다른 탄천 구간을 시험했다.
동일 출발·도착, 원본 보행 노드에서 선택한 경유점 5개, 실제 카카오 도보 REST 응답만 사용했다.
전체 앱 추천으로 연결하지 않았고 원천호수 입력과 기존 탄천 141.4m 입력을 보존했다.

- **탄천:** OSM `way/1285366992`의 연결된 24개 node, 원본 선형 527.1m.
  `highway=footway`, `bicycle=no`, 방향 보행 그래프에서 요청 순서와 복귀가 연결된다.
  출처는 기존 `river-walkways.osm.json`의 `2026-10-07T15:48:57.974580+00:00` 수집 자료다.
  하천 중심선과의 최대 차이는 약 90m이며 중심선 근접만으로 현재 보행을 승인하지 않는다.
- **신대호수:** OSM `relation/10744610`, `name=신대저수지`, `natural=water`, `type=multipolygon`.
  원본 outer `way/37221125`의 186개 node가 닫힌 수역 외곽을 구성한다.
  [수원시 관광 안내](https://www.suwon.go.kr/sw-www/sw-visitsuwon/sw-visitsuwon-01/sw-visitsuwon-01-03.jsp)에서
  신대호수 순환보행로의 존재를 확인했으나 소개 거리 3.5km를 경로 생성의 목표값으로 사용하지 않았다.
  `sindae-walkways.osm.json`은 공식 OSM Map API 응답에서 원본 외곽 250m 주변의
  보행 허용 way와 실제 node·수역 relation을 추린 독립 ODbL 자료다.
  원본 수집 시각은 `2026-10-08T16:57:44.048341+00:00`, 한국 시간 2026-10-09 01:57:44다.
  추리는 과정에서 원본 좌표·연결·태그를 변경하지 않았다.
  전체 공원 임시 응답은 새 파일로 잠시 읽은 뒤 필요한 원본 부분만 보존했다.

`source_water.py`는 실제 relation 태그와 닫힌 outer member를 함께 확인한다.
tag가 없는 outer way에 수역 태그를 임의로 부여하지 않는다.
여러 outer나 여러 way로 나뉜 outer는 아직 지원하지 않아 중단한다.
신대호수 inner 6개는 목록만 보존하며 섬·내부 경계는 면 모델에 반영하지 않는다.
따라서 이번 수역 판정은 **외곽 전체 포함** 검사이며 섬 위의 길을 물 위의 길로 확정하지 않는다.
[OSM multipolygon 문서](https://wiki.openstreetmap.org/wiki/Relation:multipolygon)의 outer/inner 구분을 따른다.

신대호수는 평균점이 외곽 밖에 있어, 분석용 회전 기준점만 원본 경계의 내부 scanline 구간에서 계산했다.
이 점은 산책 입력·경로 좌표로 쓰거나 반환하지 않는다. 산책 좌표는 실제 원본 node 그대로다.
외곽 전체를 감싸는 연결된 원본 순환은 확보한 그래프에서 찾지 못했다.
따라서 실제 호숫가 노드 8개로 API 시험 입력을 준비했고 이것이 한 바퀴라는 전제는 두지 않았다.
S·경유점 5개는 원본 허용 보행 노드와 일치하고 원본 방향 그래프로 순서·복귀가 연결됨을 확인했다.
현재 출입·통제·장벽은 미확인이다.

## 결과 해석

**탄천:** API 거리 1,164m는 원본 구간의 단순 왕복 1,054.2m보다 109.8m(약 10.4%) 길다.
API 선형 길이는 1,128.4m이며 원본·API 형상과 거리 산정 차이, 출발/반환점 처리의 추가 대조가 필요하다.
같은 끝점 쌍의 선분 재통과 하한은 423.9m(37.57%)다. 왕복에서는 반복이 의도된 조건이므로
이 비율을 호수의 불필요 반복과 같은 의미로 평가하지 않는다.
지도에서 하천 옆 선형과 S·1–5 표시를 확인했지만 이미지 한 장만으로 왕복 방향이나 현재 통행을 확정하지 않았다.
두 탐색 방식이 같은 검사 수치를 반환했으며 모든 장소에서 동일하다고 일반화하지 않는다.

**신대호수:** 원래 시험 입력은 외곽 꼭짓점 51개가 경로 밖이고 수역 경계 선분 4개와 교차했다.
수역 격자 258개 중 포함 비율은 86.82%, 제외된 경계와 경로의 최대 차이는 255.0m였다.
단순 복귀와 근접 비율 95.81%로 한 바퀴라고 승인하지 않는다.

북쪽 비교에서는 5번을 `node/5630494838`에서 `node/5630528162`로 별도 지정했다.
원본 점 사이의 이동은 **381.2m**다. 기존 시험 파일을 수정하거나 원래 요청을 몰래 대체하지 않았다.
`via_sample_indices=[1,2,4,5,7]`로 고정된 원본 목록에서 선택했고 다른 4개 경유점·출발점은 같다.
기존 기본 선택은 `[1,2,4,5,6]`다. 임의 좌표나 반환 API 좌표를 새로운 입력으로 저장하지 않았다.

비교 경로는 단순 닫힌 선형이며 같은 정확한 선분 반복 진단은 0m다.
수역 격자 258개는 전부 순환 횟수 -1이지만 **격자 성공은 최종 판정이 아니다**.
실제 외곽 꼭짓점 9개가 밖에 남고 경계 선분 6개와 교차한다. 최대 경계 차이는 35.5m다.
배경지도에서는 둘레를 도는 형태지만 경계 자료의 정확도·보행 데크·현재 출입을 대조하기 전까지
검사를 성공으로 바꾸거나 최종 추천으로 연결하지 않는다.
